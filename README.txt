Syed Muhammad Shah - Portfolio Website

Folder structure:
  index.html      main page (all content)
  css/style.css   design (colors are at the top under :root)
  js/script.js    small script (footer year)

How to use:
  Open index.html in a browser, or upload the whole folder to any hosting.
  The page needs internet only to load Google Fonts (it has fallbacks).

Change colors: edit the variables at the top of css/style.css
  --brand (main blue), --soft (light blue), --mark (accent), --ink (text).
